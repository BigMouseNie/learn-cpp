## 常见 `mode` 模式

| 模式     | 含义                                   |
| -------- | -------------------------------------- |
| `"r"`    | 只读，文件必须存在                     |
| `"w"`    | 只写，**文件存在则清空**，不存在则创建 |
| `"a"`    | 追加写，存在则在末尾写，不存在则创建   |
| `"r+"`   | 读写，文件必须存在                     |
| `"w+"`   | 读写，文件存在则清空，不存在则创建     |
| `"a+"`   | 读写，写时追加，不存在则创建           |
| 加 `"b"` | 以二进制模式打开，如 `"rb"`、`"wb"`    |
